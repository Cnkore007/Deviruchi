# 服务端权威 + 混合同步策略

自己角色使用客户端预测（Predicted Entity），按键后立即移动，服务端回包校正偏差。其他角色和 Mob 使用服务端位置插值（Interpolated Entity），20 tick/s 固定推送，客户端插值平滑渲染。所有游戏逻辑由服务端权威校验，客户端仅负责渲染和输入。

**Considered Options:**
- 纯服务端权威 + 插值 — 实现简单但操作有 50ms 延迟感
- 纯客户端预测 — 手感好但无法防作弊
- 混合（选定方案）— 自己预测保证手感，他人插值保证安全

**Consequences:** 需要实现两套渲染逻辑（预测 + 插值），但这是 RO 类游戏的标准做法。服务端需要检测移动速度和攻击频率异常作为反作弊补充。
